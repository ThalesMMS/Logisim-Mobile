# Symbol appearance editing

`appearanceEditorTool()` edits the active circuit's symbol as a draft. The preview supports selecting and dragging supported shapes, real-pin ports, and the anchor. The inspector edits position, dimensions, radii, fill and outline colors, text and font, layer order, port coordinates, and anchor facing. Apply updates every referencing instance and its boundary wires as one project edit through the editor's history. Rejected rebinding leaves the original project intact. Classic appearance can be restored with the same atomic rebinding.

`SymbolAppearance` represents rectangular/elliptical/line/polygon/path/text shapes, an oriented anchor, and exactly one appearance port per actual circuit pin. Ports keep the real pin ID; `.circ` serialization emits the real pin coordinate and direction expected by desktop Logisim. Canonical offsets normalize the anchor facing before applying an instance rotation, avoiding a second rotation of non-east anchors.

Unknown XML objects and comments remain opaque and are serialized unchanged. Transforms, styles, clipping, unsupported SVG path commands, and unsupported dynamic desktop appearance elements are preserved as XML. To add an indicator for an LED in the active circuit, choose **+ LED state** and select the component. Drag the indicator or edit its position and radius, then apply the draft. The symbol uses the LED state of each subcircuit instance and writes a desktop-compatible `visible-led` reference. Nested component paths and other indicator types remain opaque. The panel displays that limitation. Bounds union all supported shapes and ports, rather than using only the first rectangle. Standard SVG text/shape attributes and `circ-port`/`circ-anchor` are used in output.

Use `SymbolVisuals.symbolInstance` for the host canvas and export renderer when the referenced child has a custom appearance. Install the custom instance's derived named ports/bounds/text through `AppearanceEdits.bind`, or let `AppearanceEdits.apply` rebind all parents. Tests cover classic desktop geometry, a north-facing anchor, unknown XML/comments, port/wire movement with undo, invalid bindings, shape union bounds, and real-pin movement without breaking stored pin references. Full desktop reopening and pointer/touch flow remain host integration checks.
