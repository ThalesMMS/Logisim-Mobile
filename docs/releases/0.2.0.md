# Logisim Mobile 0.2.0

Build 2 uses the application identifier `thalesmms.logisim.mobile` on Android and iOS. This identifier is separate from the earlier `dev.logisim.mobile` prototype. Export `.circ` projects from the prototype before uninstalling it.

This build adds multi-circuit projects, multibit simulation, event propagation, ROMs, registers, counters, splitters, and the original SAP-1 example. The SAP-1 validation matches 5,152 desktop observations and produces `08` at half-cycle 56. The editor includes adaptive panels, touch navigation, editable properties, and recoverable project checkpoints.

The application has an original circuit-gate icon. Android and Apple hosts share one version and build definition in `app.properties`.

This remains an independent port with partial desktop parity. The compatibility matrix documents unsupported components and remaining platform validation. These notes do not constitute approval for store distribution or verification on physical devices.
