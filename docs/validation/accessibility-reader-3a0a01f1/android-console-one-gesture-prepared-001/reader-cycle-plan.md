# Public setup and restoration for the single-contact unit

Status: `PREPARED_NOT_EXECUTED`. This is the operator sequence for a future Root lease. It creates no authorized lease, enables no reader and sends no event during preparation.

The operator completes this cycle directly. In Settings, use only serial-specific raw screenshots and observed public controls. Capture screenshots with `adb -s emulator-5556 exec-out screencap -p`; normal public Settings taps/key navigation are setup and cleanup, not evidence of reader navigation. These operations do not request UiAutomation and do not suppress services. No UI Automator CLI is used, including while the reader is off. There is no arbitrary-package SDK exception. In the app, every tree comes from the existing preserve-only SDK client.

1. Record installed app/test/helper hashes, viewport, font, IME, rotation, notification grant/flags and public reader state. Require the original reader disabled. Record speech display and ERROR before any change. Preserve all existing public values and the original files.
2. While the reader is off, prepare the existing paused editor through observed public controls. Close only transient test dialogs using their observed cancel/close action and hide the keyboard. Do not import a fixture, change circuit values or edit the document. Retain the app screenshot/tree and visible circuit geometry.
3. Open public Accessibility Settings with the documented `android.settings.ACCESSIBILITY_SETTINGS` intent. Observe TalkBack, then its Settings, Advanced settings and Developer settings. Enable only Display speech output; preserve log level ERROR, Explore by touch, gestures, shortcuts, single-tap behavior and every other preference. Record before/after screenshots.
4. Return to the public Use TalkBack switch and enable it with the standard full-control confirmation. Capture every resulting screen. If a notification prompt reappears, verify the original grant was false and choose only the observed Don't allow action. An unexpected permission or configuration outside this plan stops setup and enters public restoration. A default tutorial may be closed through its observed public Close action without changing preferences.
5. Start one continuous screen recording before publicly returning to the app, so the initial reader caption is retained even if it disappears before a sampled screenshot. The record must cover the baseline, complete contact, subsequent caption and focus. Never infer audio from the video stream.
6. Publicly return to the already installed app without an import or fixture intent. Capture actual AMS binding plus actual accessibility Bound/touch state before and after the preserve-only SDK baseline. Require the expected user and foreground paused app without a modal or keyboard. Freeze the actual unique reader focus A and its matching caption. Confirm the fixed contact region is neutral. If any precondition is missing, do not force focus or send a gesture.
7. Root may now issue a fresh single-use lease tied to the reviewed wrapper, contact and plan hashes. Execute the prepared driver once. It starts the bounded passive trace, waits for device/name readiness, sends the fixed Type B contact and attempts its UP. The driver never enables TalkBack, clicks an app control or qualifies reader behavior.
8. Retain the post-contact preserve-only SDK tree/screenshot and AMS/accessibility evidence around that capture. Review the passive trace and recorded reader caption. Require one new focus B distinct from A and the whole Canvas node, outside the neutral contact region, plus matching reader text and stable circuit viewport. Do not send another gesture, activate a control or choose an alternate transport.
9. After kernel closure is verified, or after confirming no Down was attempted, open public Accessibility Settings while the reader remains on. Use screenshots and observed public Settings controls to turn TalkBack off and confirm Turn off. No CLI hierarchy dump is used. Confirm the public switch, enabled-service setting, actual Bound state and touch-exploration state are restored. A missing UP, nonterminal observer or unverified cleanup keeps the lane with its owner for Root recovery.
10. With the reader off, return to Developer settings and restore Display speech output to its original value. Capture the restored switch and ERROR. Recheck notifications, font, IME, rotation, viewport/display metadata and all three APK hashes. Preserve and report any document/viewport difference without claiming opaque settings or exact view state were restored. Stop the owned recording, retain its bytes and return the lane explicitly.

Settings screenshots are plain device framebuffer reads. AndroidUi.screen is not used there, and the SDK client's isolated-package/default behavior remains unchanged. The sole proposed reader interaction in the app is the hardware contact. This plan does not qualify a Settings reader workflow, a complete app workflow, global traversal order, physical hardware, audio quality or issue #28 closure.
