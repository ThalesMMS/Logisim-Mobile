# Android Inspector validation

The dedicated Inspector scenario passed in 181.48 seconds on isolated app producer 3d231c53. The numeric width field had input focus and the software keyboard was visible. Width 0 showed the validation warning and disabled the clickable Apply ancestor; Cancel preserved the complete exported document. Width 4 changed only the known input Pin width, and one Undo restored the original XML byte-for-byte.

The retained XML, screenshots and observation record were reviewed independently. All three installed APK hashes matched the frozen app/test/helper copies after the case, and Android reported no ANR since boot.

This is an Android API35 emulator proof of this dedicated case. It does not claim physical-device ergonomics, multiselection or execution on a later main build.
